# Анкета по здоровью

Полнофункциональный сайт для сбора анкет по здоровью с поддержкой двух языков (RU/EN) и интеграцией с Telegram API.

## Особенности

- 🎨 Современный wellness-дизайн
- 🌍 Двуязычность (русский/английский)
- 📱 Полная адаптивность для мобильных устройств
- 📋 4 типа анкет (малыши, дети, женская, мужская)
- 🔄 Пошаговая навигация с индикатором прогресса
- ✅ Валидация полей
- 🔀 Условная логика для полей
- 📤 Интеграция с Telegram Bot API
- 📄 Страница Impressum (для соответствия европейским законам)
- ✅ Согласие на обработку данных

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Сайт будет доступен на `http://localhost:3000`

## Настройка Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/botfather) в Telegram
2. Получите токен бота
3. Получите ID чата или группы, куда будут отправляться анкеты
4. Откройте файл `src/utils/telegram.ts`
5. Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота
6. Замените `YOUR_CHAT_ID_HERE` на ID чата/группы
